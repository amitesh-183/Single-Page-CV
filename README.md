# B. Amitesh — Frontend Developer CV

A responsive, single-page CV built with semantic HTML and custom CSS. It includes professional experience, selected projects, technical skills, education, SEO metadata, Open Graph metadata, and an SVG favicon.

## View locally

Open `index.html` in a browser. No build step or package installation is required.

## Project files

- `index.html` — CV content and page metadata
- `styles.css` — responsive layout, typography, and visual styling
- `favicon.svg` — browser tab icon
